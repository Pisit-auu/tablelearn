# TableLearn — ตัวช่วยจัดตารางเรียนสำหรับนักศึกษา มจพ.

**TableLearn** เป็นเว็บช่วยวางแผนลงทะเบียนเรียนสำหรับนักศึกษา **มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ. / KMUTNB)** ดึงรายวิชาและ section จริงจากระบบทะเบียน มาลองจัดได้หลายแผน เห็นเวลาเรียนชนและตารางสอบชนทันที แล้วเลือกแผนที่ดีที่สุดก่อนไปกดลงทะเบียนจริง

จัดตารางร่วมกับเพื่อนได้ผ่าน **ห้องแชร์ด้วยรหัสห้อง** เพื่อให้ได้ section ตรงกัน

> **ข้อปฏิเสธความรับผิดชอบ:** เว็บนี้ไม่ใช่ระบบของมหาวิทยาลัย และไม่มีความร่วมมือหรือการรับรองจาก มจพ. ข้อมูลรายวิชาดึงมาจาก [reg.kmutnb.ac.th](https://reg.kmutnb.ac.th) ก่อนลงทะเบียนจริงควรตรวจสอบข้อมูลล่าสุดจากเว็บทะเบียนทุกครั้ง

## ฟีเจอร์

### ดึงรายวิชาจากระบบทะเบียน มจพ.
- ค้นหารายวิชาด้วยตัวกรอง **ปีการศึกษา / ภาคเรียน / วิทยาเขต / ระดับ / คณะ / ภาควิชา / ชุดวิชา** และค้นด้วยรหัสหรือชื่อวิชา
- section ที่เรียนหลายคาบจะถูกแตกเป็นหลายบล็อกในตารางให้อัตโนมัติ
- ดึง **วันสอบกลางภาคและปลายภาค** มาด้วย

### จัดตาราง
- **หลายตาราง (plan):** เพิ่ม ลบ เปลี่ยนชื่อ และสลับตารางได้ ใช้ลองหลายแบบและเก็บแผนสำรอง
- **ตัวช่วยจัดแผนอัตโนมัติ:** เลือกวิชาที่ต้องการ ตั้งเงื่อนไขเวลาเรียนเร็วสุด/ช้าสุด เลือกวันที่ไม่อยากเรียน และให้หลีกเลี่ยงเวลาชน ระบบจะสร้างแผนพร้อมคะแนนและเหตุผล
- **ล็อกรายวิชา:** บังคับให้ตัวช่วยจัดแผนคงวิชาหรือ section นั้นไว้
- **เปรียบเทียบ 2 แผน:** ดูสถิติเทียบกัน วิชาที่มีเฉพาะแผน A หรือ B และกดสลับไปใช้แผนที่เลือกได้
- **เพิ่มหรือแก้รายวิชาเอง:** รหัส ชื่อ หน่วยกิต วัน เวลา ห้อง อาจารย์ วันสอบกลางภาค/ปลายภาค และสี

### มุมมองและสรุปผล
- **มุมมองตาราง:** กริดวัน × เวลา ช่วง 07:00–20:00
- **มุมมองรายการรายวัน:** เรียงวิชาตามเวลา แสดงช่องว่างระหว่างคาบ เหมาะกับมือถือ
- **สรุปอัตโนมัติ:** จำนวนวิชา หน่วยกิตรวม จำนวนคู่ที่เวลาชน จำนวนวิชาที่มีสอบ และเวลาว่างแต่ละวัน
- **คำเตือนตารางสอบ:** แจ้งเมื่อวันสอบชนกันหรือสอบติดกัน

### ส่งออกและแชร์
- **Import / Export Excel** (ไฟล์ไม่เกิน 1 MB และไม่เกิน 80 แถว)
- **บันทึกตารางเป็นรูป PNG** สำหรับโพสต์หรือส่งต่อ
- **ห้องตารางร่วมกัน** ด้วยรหัสห้อง ซิงก์อัตโนมัติทุก 2 วินาที (ดูหัวข้อ [ห้องตารางร่วมกัน](#ห้องตารางร่วมกัน))

## เริ่มต้นใช้งาน

### สิ่งที่ต้องมี
- **Node.js 20.9** ขึ้นไป (Next.js 16)
- **PostgreSQL** ที่รองรับ SSL (เช่น Neon, Supabase, Vercel Postgres) — จำเป็นเฉพาะถ้าจะใช้ห้องแชร์

### ขั้นตอน

```bash
# 1. Clone โปรเจกต์
git clone https://github.com/Pisit-auu/tablelearn.git
cd tablelearn

# 2. ติดตั้ง dependencies
npm install

# 3. (ถ้าจะใช้ห้องแชร์) สร้างไฟล์ .env.local ใส่ connection string ของ Postgres

# 4. รัน development server
npm run dev
```

เปิด [http://127.0.0.1:3005](http://127.0.0.1:3005) (สคริปต์ `dev` ผูกไว้ที่ host `127.0.0.1` พอร์ต `3005`)

- **ไม่ต้องสร้างตารางเอง:** ครั้งแรกที่มีการใช้ห้องแชร์ ระบบจะสร้างตาราง `shared_plans` และ `shared_courses` ให้อัตโนมัติ
- **ไม่ตั้งค่าฐานข้อมูลก็ได้:** ฟีเจอร์อื่นทั้งหมดใช้งานได้ปกติ เพราะตารางส่วนตัวเก็บใน `localStorage` ของเบราว์เซอร์

## Environment Variables

สร้างไฟล์ `.env.local` ที่ root ของโปรเจกต์ (`.env` และ `.env*.local` อยู่ใน `.gitignore` แล้ว):

```env
# ใช้ตัวใดตัวหนึ่ง ระบบอ่าน POSTGRES_URL ก่อน ถ้าไม่มีจึงใช้ DATABASE_URL
POSTGRES_URL="postgresql://USER:PASSWORD@HOST:5432/tablelearn?sslmode=require"
# DATABASE_URL="postgresql://..."
```

| ตัวแปร | จำเป็น | คำอธิบาย |
|--------|:------:|----------|
| `POSTGRES_URL` | เฉพาะห้องแชร์ | Connection string ของ Postgres (ชื่อเดียวกับที่ Vercel Postgres ตั้งให้) |
| `DATABASE_URL` | เฉพาะห้องแชร์ | ใช้แทน `POSTGRES_URL` ได้ |

> การเชื่อมต่อบังคับใช้ SSL (`ssl: "require"`) ถ้าใช้ Postgres บนเครื่องตัวเองต้องเปิด SSL ด้วย

## วิธีใช้งาน

1. **ค้นหารายวิชา:** เลือกปีการศึกษา ภาคเรียน วิทยาเขต ระดับ คณะ และภาควิชา แล้วค้นหาด้วยรหัสหรือชื่อวิชา
2. **เพิ่มลงตาราง:** กดเพิ่ม section ที่ต้องการ ถ้าเวลาชนจะเห็นคำเตือนทันที
3. **ลองหลายแผน:** สร้างตารางใหม่เพื่อเก็บแผนสำรอง หรือใช้ตัวช่วยจัดแผนอัตโนมัติ
   - ล็อกวิชาที่ต้องลงแน่นอนก่อน
   - ตั้งเงื่อนไขเวลาและวันที่ไม่อยากเรียน
   - เลือกแผนจากคะแนนและเหตุผลที่ระบบให้มา
4. **เปรียบเทียบ:** เลือกแผน A กับแผน B เพื่อดูความต่าง แล้วสลับไปใช้แผนที่ดีกว่า
5. **ตรวจตารางสอบ:** ดูคำเตือนสอบชนหรือสอบติดกันในส่วนสรุป
6. **ส่งออก:** บันทึกเป็นรูปหรือ Excel หรือสร้างห้องเพื่อจัดตารางร่วมกับเพื่อน

## API

### Proxy ไประบบทะเบียน มจพ.

ทุก endpoint ขอ token จากระบบทะเบียนก่อน แล้วถอดข้อมูลที่ถูกบีบอัด (gzip + base64) ส่งกลับเป็น JSON มี rate limit **30 ครั้ง/นาที ต่อ IP**

| Method | Path | คำอธิบาย |
|--------|------|----------|
| GET | `/api/kmutnb/filters` | ตัวเลือกตัวกรอง (วิทยาเขต ระดับ คณะ ฯลฯ) |
| GET | `/api/kmutnb/departments?faculty=<id>` | ภาควิชาของคณะ |
| GET | `/api/kmutnb/classes` | รายวิชาและ section |

พารามิเตอร์ของ `/api/kmutnb/classes`:

| พารามิเตอร์ | ค่าเริ่มต้น | ความหมาย |
|-------------|-------------|----------|
| `year` | `2569` | ปีการศึกษา |
| `semester` | `1` | ภาคเรียน |
| `campus` | `10` | รหัสวิทยาเขต |
| `level` | `61` | รหัสระดับการศึกษา |
| `faculty` | `4` | รหัสคณะ |
| `department` | `406` | รหัสภาควิชา |
| `division`, `courseCode`, `courseName`, `classSet`, `officer` | — | ตัวกรองเพิ่มเติม |

### ห้องแชร์

| Method | Path | Rate limit | คำอธิบาย |
|--------|------|------------|----------|
| GET | `/api/shared-plans/{id}` | 120 ครั้ง/นาที | อ่านข้อมูลห้อง (`404` ถ้าไม่พบ) |
| PUT | `/api/shared-plans/{id}` | 30 ครั้ง/นาที | บันทึกห้อง ส่ง edit token ใน header `x-edit-token` (`403` ไม่มีสิทธิ์, `409` ข้อมูลเก่ากว่าบนเซิร์ฟเวอร์) |

หน้าเว็บเรียกผ่าน Server Actions ใน `app/actions/shared-plans.ts` ซึ่งใช้ชั้นข้อมูลเดียวกัน

> rate limit เก็บในหน่วยความจำของแต่ละ instance ถ้า deploy หลาย instance หรือแบบ serverless ตัวนับจะแยกกัน

## การ Deploy

เหมาะกับ **Vercel** ที่สุด

1. Import repo เข้า Vercel
2. (ถ้าใช้ห้องแชร์) เพิ่ม Postgres จาก Storage ของ Vercel ระบบจะตั้ง `POSTGRES_URL` ให้อัตโนมัติ หรือใส่ `DATABASE_URL` เอง
3. กด Deploy

deploy บน Node server อื่นได้ด้วย `npm run build && npm run start` (ค่าเริ่มต้นของ `next start` คือพอร์ต 3000)

- เวลาชนและสถานะต่าง ๆ มีข้อความกำกับเสมอ ไม่ได้สื่อด้วยสีอย่างเดียว
