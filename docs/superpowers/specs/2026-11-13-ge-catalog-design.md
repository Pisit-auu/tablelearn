# แค็ตตาล็อกวิชาศึกษาทั่วไป (GE): ร่างการออกแบบฉบับย่อ

## เป้าหมายและเหตุผล
นักศึกษามักเข้ามาหาว่ามีวิชาเลือกให้ลงอะไรบ้าง: รหัสอะไร กี่หน่วยกิต อยู่กลุ่มไหน และเปิดเทอมไหน ตอนนี้ TableLearn มีแค่ข้อมูลกลุ่มเรียนที่ดึงมาจากระบบทะเบียน ต้องรู้รหัสวิชาก่อนถึงจะค้นได้ ส่วนนี้จะให้เลือกดูรายวิชา GE ได้ก่อน แล้วค่อยไปดูกลุ่มเรียน

## ขอบเขต
- **ทำ:** เพิ่มส่วนใหม่ "วิชาศึกษาทั่วไป" ในแถบเมนู (`zones` ใน `app/page.tsx`) แสดงรายวิชา GE ของหลักสูตร ป.ตรี 4–5 ปี ฝั่ง มจพ. กรุงเทพฯ/ปราจีนบุรี จากเล่มรายวิชาศึกษาทั่วไป ฉบับปี พ.ศ. 2566
- **แต่ละวิชาแสดง:** รหัสวิชา ชื่อวิชา (ไทย/อังกฤษ) หน่วยกิต และกลุ่มวิชา GE (มี 5 กลุ่ม: ภาษาและการสื่อสาร / ผู้ประกอบการและนวัตกรรม / ทักษะศตวรรษที่ 21 / คุณภาพชีวิตและพลเมือง / กีฬาและนันทนาการ)
- **ตัวกรอง:** ปุ่มเลือกกลุ่มวิชา และช่องค้นหาด้วยรหัสหรือชื่อวิชา
- **ปุ่ม "ดูกลุ่มเรียน" ของแต่ละวิชา:** เปิดหน้าต่างดึงรายวิชาเดิม ใส่รหัสวิชาให้แล้วโหลดทันที ใช้ปีและเทอมที่ตั้งไว้ในหน้าต่างนั้น ผู้ใช้จึงเห็นว่าเทอมนั้นมีกลุ่มเรียนหรือไม่ แล้วนำเข้าตารางหรือตัวช่วยจัดแผนได้ตามปกติ
- **บรรทัดแหล่งที่มา:** "รายวิชาจากเล่มรายวิชาศึกษาทั่วไป ฉบับปี พ.ศ. 2566" พร้อมลิงก์ไปที่ acdserv.kmutnb.ac.th (ผู้ใช้ส่งลิงก์เต็มมาให้)

## สิ่งที่ไม่ทำ
- คำอธิบายรายวิชา, วิชาบังคับก่อน, ตารางโครงสร้างหน่วยกิต, GELOs
- นิยามหรืออธิบายคำว่า "วิชาเสรี"
- สถานะเปิด/ไม่เปิดในเทอมนี้ที่คำนวณไว้ล่วงหน้าหรือดึงสด ให้ดูผ่านปุ่ม "ดูกลุ่มเรียน" แทน
- รายวิชาของหลักสูตรนานาชาติ วิทยาเขตระยอง และ ป.ตรีต่อเนื่องของวิทยาลัยเทคโนโลยีอุตสาหกรรม

## ทางเลือกที่พิจารณา
1. **ข้อมูลเล่มอย่างเดียว พร้อมปุ่มดูกลุ่มเรียน (ผู้ใช้เลือกทางนี้):** งานเล็ก ไม่ดึงข้อมูลจากระบบทะเบียนเพิ่ม และใช้หน้าต่างดึงรายวิชาเดิม
2. ข้อ 1 บวกป้าย "เปิดเทอมนี้" ที่ดึงสด: ต้องดึงทั้งวิทยาเขตประมาณ 3,000 แถวต่อการเปิดหน้า และต้องทำแคชเพิ่ม จึงตัดออก
3. ใส่ข้อมูลเปิดเทอมไว้ล่วงหน้า: ข้อมูลจะเก่าทุกเทอมและทำให้เข้าใจผิด จึงตัดออก

## ข้อมูล
- ไฟล์ข้อมูลคงที่ในโค้ด (เช่น `app/ge/ge-courses.ts`) แต่ละแถวมี `{ code, nameTh, nameEn, credits, group }` และมีธงเพิ่มได้ 2 อย่าง
  - `required`: วิชาบังคับ GE เช่นภาษาอังกฤษ 1/2 ให้แสดงป้าย "บังคับ"
  - `citOnly`: วิชาที่เล่มระบุว่าเปิดเฉพาะวิทยาลัยเทคโนโลยีอุตสาหกรรม ให้แสดงป้ายเตือน
- แหล่งข้อมูลคือรายการที่ดึงจาก PDF ได้แล้ว (หน้า 28–30, 45–46, 56–59, 79–82, 104–105) ทั้งหมด 139 วิชา ไม่รวมวิชาของหลักสูตรนานาชาติ ตรวจกับเล่มต้นฉบับแบบสุ่มแล้วตรงกัน

## สิ่งที่ปล่อยให้ผู้ลงมือตัดสินใจ (คำแนะนำของผม)
- **หน้าตา:** ใช้ธีม reg.kmutnb ที่มีอยู่และคลาสใน `globals.css` เป็นรายการแบบกะทัดรัด ดูได้ทั้งมือถือและเดสก์ท็อป
- **ปุ่ม "ดูกลุ่มเรียน" ต้องโหลดด้วยรหัสที่ส่งเข้าไปตรง ๆ:** `loadRemoteClasses` อ่านค่า `courseSearch` จาก state ถ้าตั้ง state แล้วเรียกฟังก์ชันทันทีจะได้ค่าเก่า จึงต้องให้ฟังก์ชันรับรหัสเป็นพารามิเตอร์ได้
- **ตำแหน่งในแถบเมนู:** วางไว้หลัง "รายวิชา" และพับไว้เป็นค่าเริ่มต้นเหมือนส่วนอื่น
- **การทดสอบ:** มี unit test ของตัวกรองและค้นหาแบบ pure function ตามแนวทาง `node --test` ที่ใช้อยู่
