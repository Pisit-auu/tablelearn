# ภารกิจเริ่มต้นใช้งาน + พาทำจริง + ปุ่ม ? — Design

วันที่: 2026-11-11 · สถานะ: รอผู้ใช้อนุมัติ

## ทำไมต้องทำ

มี feedback จากผู้ใช้ว่า "เว็บใช้ยากมาก" ตรวจโค้ดแล้วพบว่า

1. ไม่มีอะไรสอนใช้เลย หน้าเป็นหน้ายาวหน้าเดียว 8 ส่วน (`face`, `blocks`, `planner`, `compare`, `voids`, `exams`, `room`, `feedback`) คนเข้ามาครั้งแรกเห็นตารางว่างแต่ไม่รู้ว่าต้องเริ่มตรงไหน
2. ตัวช่วยจัดแผน (ฟีเจอร์เด่น) ต้องทำข้ามสองที่: เปิดหน้าต่าง "ดึงรายวิชาจากเว็บ" → ค้นหา → "เลือกเข้าตัวช่วยจัดแผน" → ปิดหน้าต่าง → เลื่อนลงไปส่วนตัวช่วยจัดแผน → ติ๊ก → "สร้างแผนที่เป็นไปได้" → "ใช้แผนนี้" น่าจะหลุดตอนปิดหน้าต่างแล้วไม่รู้ว่าวิชาไปอยู่ไหน
3. ความเชื่อมโยงที่มองไม่เห็น เช่น ล็อกวิชาใน "รายวิชาที่บันทึก" ทำให้ตัวช่วยจัดแผนไม่สลับ section

เป้าหมาย: ผู้ใช้ใหม่ทำตารางของตัวเองด้วยตัวช่วยจัดแผนได้สำเร็จในการเข้าครั้งแรก โดยไม่ต้องมีคนสอน

## สิ่งที่ผู้ใช้ตัดสินใจแล้ว

- มีสามส่วน: **แผงภารกิจเริ่มต้นใช้งาน** (แบบ checklist มีแถบความคืบหน้า, อ้างอิงภาพตัวอย่างจากเว็บอื่นที่ผู้ใช้ส่งมา), **บทพาทำ (guided tour)**, **ปุ่ม ?** ตามจุดต่าง ๆ
- บทพาทำ **ให้ผู้ใช้ทำจริง**: ชี้ไปที่ปุ่ม แล้วรอจนผู้ใช้กดเอง/ทำสำเร็จจริงก่อนไปขั้นถัดไป จบแล้วได้ผลลัพธ์จริงติดมือ (ไม่ใช่สไลด์กด "ถัดไป")
- หน้าตา: หน้าจอมืดลงเหลือสว่างเฉพาะเป้าหมาย, วงกระพริบรอบเป้าหมาย, มือชี้ขยับ, การ์ดอธิบายภาษาง่าย ๆ มี "ขั้นที่ X จาก N" + จุดความคืบหน้า + "ข้ามบทเรียน", เลื่อนจอไปหาเป้าหมายให้เองถ้าอยู่นอกจอ ("ไฮเทค" ตามที่ผู้ใช้ขอ) ภาพร่างที่ผู้ใช้ยืนยัน: `.superpowers/brainstorm/77799-1794368866/content/tour-overview.html`
- ภารกิจ 5 ข้อ:
  1. รู้จักหน้าเว็บ (เดิม "ดูตัวอย่างตาราง" — เปลี่ยนตามที่ผู้ใช้เลือก เพราะเว็บไม่มีตารางตัวอย่าง)
  2. จัดแผนด้วยตัวช่วยจัดแผน
  3. ล็อกวิชาที่ต้องได้
  4. เทียบ 2 แผน
  5. ชวนเพื่อนเข้าห้อง
- กดข้อไหนในแผงภารกิจ = เริ่มพาทำข้อนั้น ข้อจะติ๊ก "สำเร็จแล้ว" เมื่อทำสำเร็จจริงเท่านั้น และติ๊กให้ด้วยถ้าผู้ใช้ทำเองโดยไม่ผ่านบทพาทำ
- แผงภารกิจ **เปิดขึ้นมาเองเฉพาะการเข้าเว็บครั้งแรก** ครั้งต่อไปย่อเป็นปุ่มเล็กมุมจอพร้อมตัวเลขความคืบหน้า (เช่น 2/5) กดแล้วเปิดแผงได้ตลอด
- ปุ่ม ? กดแล้วเด้งคำอธิบายสั้น 2–3 บรรทัด ภาษาง่าย พร้อมปุ่ม "พาทำให้ดู" (ถ้าส่วนนั้นมีบทพาทำ)

## ข้อตัดสินใจที่ผู้ใช้รับรองแล้ว (Claude เสนอ ผู้ใช้ตอบ "ถูกต้อง")

- **มือถือ**: แผงภารกิจเป็น bottom sheet เลื่อนขึ้นจากล่าง, การ์ดอธิบายของบทพาทำอยู่ล่างจอเพื่อไม่บังเป้าหมาย วงกระพริบ/มือชี้เหมือนเดสก์ท็อป
- **เก็บความคืบหน้าใน localStorage** แบบเดียวกับตารางส่วนตัว ไม่มีล็อกอิน เปลี่ยนเครื่อง/ล้างเบราว์เซอร์ = เริ่มนับใหม่
- **เงื่อนไขสำเร็จของแต่ละภารกิจ**:
  1. รู้จักหน้าเว็บ → ดูทัวร์สั้นจนจบ (ดูหัวข้อบทพาทำ)
  2. จัดแผน → กด "ใช้แผนนี้" สำเร็จ (`applyGeneratedPlan`)
  3. ล็อกวิชา → มีวิชาถูกล็อกอย่างน้อย 1 วิชา (`toggleCourseLocked` ให้ผลเป็น locked)
  4. เทียบ 2 แผน → ผู้ใช้เปลี่ยนช่องเลือกแผน A หรือ B เองอย่างน้อยครั้งหนึ่ง และ A ≠ B (ค่าเริ่มต้นของช่องเลือกเป็น A=ตารางแรก B=ตารางที่สองอยู่แล้ว และ `applyGeneratedPlan` เพิ่มตารางใหม่เสมอ ถ้าดูแค่ state ภารกิจนี้จะติ๊กเอง — Claude's call)
  5. ชวนเพื่อน → สร้างห้องหรือเข้าห้องสำเร็จ
- **ข้ามได้ทุกขั้น** ด้วย "ข้ามบทเรียน" (และ Esc) ข้ามแล้วภารกิจไม่ติ๊ก
- **ห้องโหมดดูอย่างเดียว** (`!canEditActivePlan`): ไม่เริ่มบทพาทำที่ต้องแก้ตาราง แจ้งสั้น ๆ ว่าห้องนี้แก้ไขไม่ได้
- **ปุ่ม ? ครบ 8 ส่วนหลัก** ข้างหัวข้อของแต่ละ zone Claude ร่างข้อความ (ด้านล่าง) ให้ผู้ใช้ตรวจ
- **prefers-reduced-motion**: ไม่มีวงกระพริบ/มือขยับ/เลื่อนแบบ smooth ใช้กรอบไฮไลต์นิ่งแทน

## ข้อตัดสินใจของ Claude หลังอ่านทวน (ผู้ใช้ยังไม่ได้ยืนยันทีละข้อ)

- **นับสำเร็จจากการกระทำของผู้ใช้เท่านั้น** (เรียกจาก handler เดิม เช่น `applyGeneratedPlan`, `toggleCourseLocked`, `createSharedRoom`/`enterSharedRoom`, onChange ของช่องเทียบแผน) ไม่ดูจาก state ตอนโหลด และไม่นับสิ่งที่เพื่อนทำในห้องที่ sync เข้ามา — กันภารกิจติ๊กเองทั้งที่ไม่ได้ทำ
- **ผู้ใช้เดิม** (มีตารางใน localStorage แล้ว) ถือเป็น "ครั้งแรก" ของฟีเจอร์นี้: แผงภารกิจเปิดเองหนึ่งครั้ง ภารกิจเริ่มที่ 0/5 เหมือนผู้ใช้ใหม่
- **เข้ามาครั้งแรกผ่านลิงก์ห้อง (`?room=`)**: ไม่เปิดแผงเอง แสดงแค่ปุ่มย่อมุมจอ (ไม่นับว่าเปิดครั้งแรกแล้ว — ครั้งถัดไปที่เข้าแบบไม่มี `?room=` ค่อยเปิดเอง)
- **overlay ไม่บล็อกการคลิก** เพราะหลายขั้นต้องใช้หลายปุ่ม (ตัวกรอง, หลายการ์ด, checkbox) ส่วนที่ไม่ใช่เป้าหมายแค่มืดลง ถ้าผู้ใช้ออกนอกบท (ปิดหน้าต่างก่อนเวลา, ย่อส่วน, เลื่อนหนี) บทพาทำ**ถอยไปขั้นแรกสุดที่เงื่อนไขยังไม่ครบ** แล้วชี้ใหม่ ไม่ค้าง ไม่ออกจากบทเอง; ถ้าเป้าหมายมองไม่เห็นให้เลื่อน/unfold ให้

## บทพาทำ

### ภารกิจ 2: จัดแผนด้วยตัวช่วยจัดแผน (บทหลัก 6 ขั้น)

| ขั้น | เป้าหมายที่ชี้ | ข้อความ (ร่าง) | ไปขั้นถัดไปเมื่อ |
|---|---|---|---|
| 1 | ปุ่ม "ดึงรายวิชาจากเว็บ" (rail; บนมือถือคือปุ่มที่เทียบเท่า) | เริ่มจากหาวิชาที่จะลง กดปุ่มนี้เพื่อเปิดหน้าค้นหาวิชาจากระบบทะเบียน มจพ. | หน้าต่างค้นหาเปิด |
| 2 | ตัวกรอง + ปุ่ม "ค้นหารายวิชา" ในหน้าต่าง | เลือกคณะหรือพิมพ์รหัส/ชื่อวิชา แล้วกดค้นหา | มีผลค้นหาอย่างน้อย 1 รายการ |
| 3 | ปุ่ม "เลือกเข้าตัวช่วยจัดแผน" ของการ์ดแรก | กดเก็บวิชาที่อยากลงเข้าตัวช่วย ลองเก็บอย่างน้อย 2 วิชา (หรือกด "เพิ่มทั้งหมดเข้าตัวช่วย") | คลังตัวช่วยมี ≥ 2 วิชา |
| 4 | ปุ่มปิดหน้าต่าง | วิชาถูกเก็บไว้แล้ว ปิดหน้าต่างนี้ เดี๋ยวพาไปดูว่าวิชาไปอยู่ไหน | หน้าต่างปิด → เลื่อนไปส่วน `planner` (unfold ถ้าย่ออยู่) |
| 5 | รายการ "วิชาในตัวช่วยจัดแผน" + ปุ่ม "สร้างแผนที่เป็นไปได้" | วิชาที่เก็บมาอยู่ตรงนี้ ติ๊กวิชาที่จะใช้ (ไม่เกิน 7) แล้วกดสร้างแผน ระบบจะหาชุด section ที่ไม่ชนกันให้ | มี "แผนแนะนำ" อย่างน้อย 1 แผน |
| 6 | ปุ่ม "ใช้แผนนี้" ของแผนแรก | แผนเรียงตามคะแนน ดูเหตุผลแล้วกด "ใช้แผนนี้" เพื่อใส่ลงตาราง | `applyGeneratedPlan` สำเร็จ → เลื่อนไปตาราง `face` แสดงข้อความยินดี + ภารกิจติ๊ก |

กรณีพิเศษ:
- ขั้น 5 ถ้าสร้างแผนแล้วได้ 0 แผน (ชนหมด/ล็อกหมด) การ์ดบอกเหตุผลจาก `plannerStatus` และแนะให้ลองติ๊กวิชาน้อยลง ยังรอที่ขั้น 5
- ถ้าผู้ใช้ปิดหน้าต่างก่อนถึงขั้น 4 แต่คลังมี ≥ 2 วิชาแล้ว ให้ข้ามไปขั้น 5
- ถ้าคลังตัวช่วยมีวิชาอยู่แล้วตอนเริ่ม ให้เริ่มที่ขั้น 5 ได้

### ภารกิจอื่น (บทสั้น)

- **1 รู้จักหน้าเว็บ**: ทัวร์แบบชี้ให้ดูแล้วกด "ถัดไป" (ข้อนี้ข้อเดียวไม่ต้องทำจริง เพราะไม่มีการกระทำให้ทำ — Claude's call) 4 จุด: ตารางเรียน (`face`) → ปุ่ม "ดึงรายวิชาจากเว็บ" → ส่วนตัวช่วยจัดแผน → เมนูส่วนต่าง ๆ ด้านข้าง (บนมือถือคือเมนูที่เทียบเท่า) จบแล้วติ๊กและชวนเริ่มภารกิจ 2
- **3 ล็อกวิชา**: เลื่อนไป `blocks` → ชี้ปุ่ม "ล็อก" ของวิชาแรก ("ล็อกวิชาที่ต้องได้ section นี้แน่ ๆ ตัวช่วยจัดแผนจะไม่สลับให้") → สำเร็จเมื่อล็อก ถ้ายังไม่มีวิชาในตาราง ให้บอกว่าต้องทำภารกิจ 2 ก่อน พร้อมปุ่มเริ่มภารกิจ 2
- **4 เทียบ 2 แผน**: ถ้ามีตารางเดียว ชี้ "เพิ่มตาราง" ก่อน → เลื่อนไป `compare` → ชี้ช่องเลือกแผน A/B → สำเร็จเมื่อ A ≠ B
- **5 ชวนเพื่อน**: เลื่อนไป `room` → ก่อนชี้ "สร้างห้องว่าง" การ์ด**ต้องเตือน**ว่า "ห้องใหม่จะเริ่มจากตารางว่าง ตารางส่วนตัวของคุณยังอยู่ในเครื่อง กด 'ออกจากห้อง' เมื่อไหร่ก็กลับมาเจอ" (ผู้ใช้ตัดสินใจ: เตือนอย่างเดียว ไม่แก้ฟีเจอร์ห้อง) → ชี้ "สร้างห้องว่าง" หรือช่องรหัสห้อง → สำเร็จเมื่อสร้างห้องหรือเข้าห้องได้ (เข้าห้องโหมดดูอย่างเดียวก็นับ) → ขั้นสุดท้ายชี้รหัสห้อง "ส่งรหัสนี้ให้เพื่อน" และชี้ปุ่ม "ออกจากห้อง" ว่ากลับตารางส่วนตัวได้ตรงนี้

## ปุ่ม ? (ข้อความร่างให้ผู้ใช้ตรวจ)

- **ตารางเรียนสัปดาห์นี้**: ตารางของคุณทั้งสัปดาห์ บล็อกสีแดงคือเวลาชนกัน สร้างได้หลายตารางไว้ลองหลายแบบ แล้วบันทึกเป็นรูปหรือ Excel ได้
- **รายวิชาที่บันทึก**: ทุกวิชาที่อยู่ในตารางนี้ กด "ล็อก" วิชาที่ต้องได้ section นี้แน่ ๆ ตัวช่วยจัดแผนจะไม่ยุ่งกับมัน กด "ซ่อน" ถ้าแค่อยากลองดูตารางแบบไม่มีวิชานั้น
- **ตัวช่วยจัดแผน**: เก็บวิชาที่อยากลงไว้ตรงนี้ แล้วให้ระบบหาชุด section ที่ไม่ชนกันให้ ตั้งเวลาเริ่ม/เลิกหรือวันที่ไม่อยากเรียนได้ · พาทำให้ดู
- **เปรียบเทียบ 2 แผน**: เลือกสองตารางมาวางเทียบกัน ดูหน่วยกิต เวลาชน และวิชาที่ต่างกัน · พาทำให้ดู
- **เวลาว่าง**: ช่วงว่างระหว่างคาบในแต่ละวัน ไว้ดูว่ามีเวลากินข้าวหรือทำงานไหม
- **ตารางสอบ**: วันสอบกลางภาคและปลายภาคของทุกวิชา เตือนถ้าสอบชนหรือสอบติดกัน
- **ห้องตารางร่วมกัน**: สร้างห้องแล้วส่งรหัสให้เพื่อน จะเห็นและแก้ตารางเดียวกันได้ เหมาะกับจัดให้ได้ section เดียวกัน · พาทำให้ดู
- **ข้อเสนอแนะ**: เจออะไรใช้ยาก หรืออยากได้อะไร พิมพ์บอกได้เลย

## เป้าหมาย / ไม่ใช่เป้าหมาย / สิ่งที่ถือว่าล้มเหลว

เป้าหมาย: ผู้ใช้ใหม่ทำภารกิจ 2 สำเร็จเองได้; ปุ่ม ? ตอบ "ส่วนนี้คืออะไร" ได้ในประโยคเดียว

ไม่ใช่เป้าหมาย: ไม่ redesign หน้าเว็บหรือย้าย flow ของตัวช่วยจัดแผน (แก้ความงงด้วยการสอน ไม่ใช่รื้อ); ไม่เก็บ analytics; ไม่ sync ความคืบหน้าข้ามเครื่อง; ไม่ทำ OCR (เป็น feedback อีกเรื่อง)

ถือว่าล้มเหลวแม้จะทำงานได้:
- บทพาทำบังปุ่มที่ต้องกด หรือกดเป้าหมายไม่ได้เพราะ overlay ทับ
- แผงภารกิจเด้งขึ้นทุกครั้งที่เข้าเว็บจนน่ารำคาญ
- บทพาทำค้างไปต่อไม่ได้และไม่มีทางออก
- ภารกิจติ๊กเองทั้งที่ไม่ได้ทำจริง
- ทำให้ฟีเจอร์เดิมใดพังหรือหน้าเว็บช้าลงจนรู้สึกได้

## ข้อจำกัด

- Next.js 16 App Router (อ่าน `node_modules/next/dist/docs/` ก่อนเขียน ตาม AGENTS.md), React 19, `app/page.tsx` เป็น client component เดียว ~3900 บรรทัด
- CSS ธรรมดาใน `app/globals.css` ไม่มี Tailwind/UI library — ห้ามเพิ่ม library tour (เช่น driver.js/shepherd) โดยไม่ถามผู้ใช้ก่อน (Claude's call: ทำเอง ฟีเจอร์ไม่ใหญ่)
- ใช้ token สี/ระยะ/มุมโค้งตาม `DESIGN.md` (ภาพร่างใช้ค่าคร่าว ๆ ไม่ใช่ spec)
- ข้อความ UI ภาษาไทยทั้งหมด
- ต้องเข้าถึงได้: การ์ดอธิบายอ่านด้วย screen reader ได้ (`role="dialog"`/live region), ปุ่ม ? มี `aria-label`, ใช้คีย์บอร์ดได้, Esc ปิด

## ปล่อยให้ผู้สร้างตัดสินใจ

- โครงสร้างโค้ด (แยกไฟล์ component/hook ได้ เช่น `app/onboarding/*`), วิธีหา element เป้าหมาย (แนะนำ `data-tour="..."`), วิธีตรวจว่าขั้นสำเร็จ (เรียกจาก handler เดิมหรือสังเกต state)
- วิธีทำ spotlight (box-shadow ขนาดใหญ่/SVG mask/clip-path) ตราบที่เป้าหมายยังกดได้และตามตำแหน่งเมื่อ scroll/resize
- ชื่อ key ใน localStorage และรูปแบบข้อมูล
- ตำแหน่งปุ่มย่อมุมจอ (ไม่บังเนื้อหา/ปุ่มอื่น)
- ถ้อยคำสุดท้ายของการ์ด ปรับได้ตราบที่ง่ายและสั้น
